客户端应用建议

极影加速遵循标准开放协议，你可以使用任何你习惯的核心与工具接入，无需绑定专属外壳。

Windows / macOS 桌面端

桌面办公环境建议采用支持规则分流的内核客户端（例如 Clash Verge、Sing-box 桌面版）。它们能方便地依据域名和 IP 段自动判断国内直连与海外走中继，不会干扰日常局域网和国内办公软件。

常见问答随手查

大家平时问得最多的几个小问题，这里做个详细的集中交代。

Q 套餐里的同时在线设备数怎么计算？

这个限制指的是同一时刻处于连接状态的物理终端数。比如你选了旗舰版的 5 台，你在家里电脑、平板、手机和备用机同时开着都没问题。如果外出临时多连了一台，可能会导致最先连接的设备出现握手中断，断开闲置设备即可恢复。

Q 订阅更新失败或者无法拉取节点怎么处理？

多半是因为本地客户端在拉取订阅时尝试走未建立的代理。可以先检查一下软件里的“更新订阅时绕过代理”选项是否勾选。另外也可以直接把订阅链接粘贴到普通浏览器地址栏试一下，看看文本内容能否正常读取。

Q 游戏联机和看海外剧应该选哪种节点？

如果你的套餐包含 IPLC 优化线路，玩游戏时尽量选择延迟数值平稳的就近专线节点，避开拥挤的主干道。如果是看剧，留意节点列表中标注了流媒体支持的标签，系统会自动指派具有原生 IP 广播的中转出口。

Q 每个月的流量是按自然月重置吗？

流量计数周期是根据你购买订阅的那一天开始计算的，并非统一在每月 1 号重置。你可以在面板上清楚看到当前计费周期的起止日期与剩余额度，避免月尾突发用尽。
